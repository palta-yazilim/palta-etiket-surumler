# Palta Etiket — sürümler

Bu depo yalnızca **kurulum dosyalarını** barındırır; kaynak kod burada değildir.

Programın kendisi yeni sürümleri buradan indirir. En son sürümü elle indirmek
için sağdaki **Releases** bölümüne bakın.

Dosyalar GitHub Actions tarafından kendiliğinden yüklenir; buraya elle dosya
eklemeyin. `latest.yml` güncelleyicinin okuduğu listedir.
